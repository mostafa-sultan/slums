# Git Version Control

## Introduction

Git is a distributed version control system. This tutorial covers basic Git commands, branching, and collaboration.

---

## Basic Commands

    git init
    git add .
    git commit -m "Initial commit"
    git status
    git log

---

## Branching

    git branch feature-branch
    git checkout feature-branch
    git merge feature-branch

---

## Conclusion

Git is essential for version control. Master basic commands and branching for effective collaboration.
